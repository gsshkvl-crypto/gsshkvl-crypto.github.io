# **App Name**: Versafolio

## Core Features:

- Sectional Display: Sections for: About Me, Skills, Projects, Experience, and Contact.
- Profile Links: Dedicated area to display GitHub and LinkedIn profiles.
- Project Showcases: Projects Section including 'Construction Management App' and 'ERP App for IAS Academy' with the ability to include project details and links.
- Mobile Responsiveness: Responsive design for optimal viewing on all devices.
- Content Customization: Simple configuration files for easy modification of content, colors, and fonts.
- AI-Assisted Bio Generation: AI tool for writing different drafts of a 'Summary' blurb about the user, to allow the user to get over 'writer's block'.

## Style Guidelines:

- Background color: Dark gray (#333333) for a professional, modern feel.
- Primary color: Soft gold (#B09A6F), as gold can suggest experience.
- Accent color: Muted brown (#59461B). Accents in brown to enrich the golden tones.
- Headline font: 'Space Grotesk' (sans-serif) for a techy, modern, readable feel in titles.
- Body font: 'Inter' (sans-serif) for comfortable readability in paragraphs. Paired with 'Space Grotesk', this is a readable, modern, neutral combination
- Use simple line icons for skills and sections. Consistency is key.
- Use a single-column layout for mobile, transitioning to a multi-column layout on larger screens for better content presentation.
- Subtle fade-in animations when scrolling to sections to enhance user experience without being distracting.
